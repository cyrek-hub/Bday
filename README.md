# Happy Birthday Website 💗

A single-page romantic birthday site. Just open `index.html` in a browser — no build step needed.

## Personalize it

- **Photos**: In `index.html`, find the `.gallery-placeholder` divs inside `<section id="gallery">` and replace each one with `<img src="assets/images/your-photo.jpg" alt="...">`. Put your photos in `assets/images/`.
- **The note**: In `index.html`, find `<p class="note-text">` inside `<section id="note">` and replace `[INSERT YOUR ROMANTIC BIRTHDAY NOTE HERE]` with your message. Update the `signoff-name` below it if needed.
- **Colors**: Tweak the palette in `style.css` under `:root` (`--blush`, `--rose-gold`, `--cream`, etc.).

## Files

- `index.html` — page structure
- `style.css` — all styling, animations, responsive layout
- `script.js` — floating hearts, scroll-reveal animations, hero parallax
